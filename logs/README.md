# Logs and Outputs

This directory stores outputs generated by pipeline runs to support reproducibility and analysis.

---

## What Is Logged

- Scene descriptions
- SST reasoning transcripts
- Decision outputs
- Communication messages

---

## Structure

Logs should be organized by:
- Scenario
- Video or frame ID
- Timestamp or run ID

---

## Purpose

- Experiment traceability
- Human vs LLM comparison
- Debugging and auditability
